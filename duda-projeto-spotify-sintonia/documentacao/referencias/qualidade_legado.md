# Perfil de qualidade legado — referência, não resultado oficial

Uma cópia externa analisada no projeto antigo registrava 31.819 linhas, 28.888 IDs únicos, 10.872 artistas, 15.481 álbuns e 32 gêneros.

Esses números não serão apresentados como resultado do projeto novo até serem reproduzidos no notebook a partir do dataset oficial. A observação reutilizável é que uma mesma faixa pode aparecer em mais de um gênero e não deve ser contada como faixa independente.
