# Data enrichment

This folder explains how the recommendation dataset was enlarged. The language
is intentionally simple so people and AI tools can follow the same process.

Start with `dataset_research.md` to see why each Kaggle candidate was accepted
or rejected. Then read `etl_process.md` for the repeatable steps and
`provenance.md` for source details.

The data files themselves are organized in `data/raw` (original downloads),
`data/processed` (normalized inputs and final dataset), `data/analytics`
(analysis outputs), and `data/hygiene` (validation reports).
